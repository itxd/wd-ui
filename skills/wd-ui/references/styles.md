## `flat` 扁平化（Flat Design）
- 流行时期：2012 –
- 特征：纯色块，无渐变、无纹理；去掉阴影和高光；简单几何图标
- 关键实现：`background: #3498db`、`box-shadow: none`
- 适用：工具类产品、信息图、早期移动端
- 代表：Windows Metro、iOS 7、Google 早期
- 在线样本：https://itxd.github.io/wd-ui/#st-flat

```text
风格：扁平化（Flat Design）
气质关键词：干净、直接、友好、信息优先
配色：
  - 页面背景：#ECF0F1
  - 表面：#FFFFFF
  - 主色：#3498DB
  - 辅助色：#2ECC71 / #E74C3C / #F1C40F / #9B59B6
  - 正文：#2C3E50
  - 次要文字：#7F8C8D
  - 分割线：#DFE6E9
字体：无衬线，标题 600–700，正文 400；不使用文字阴影
形状与层次：圆角 2–4px；纯色填充；完全不用渐变、纹理和投影
布局：模块之间用色块区分层级，不靠阴影；图标是单色几何形状
组件表现：
  - 按钮：纯色实心、无阴影，hover 加深约 10%
  - 卡片：白底、无边框或 1px 浅灰边、无阴影
  - 导航：深蓝灰侧栏 #2C3E50 + 主色实心选中块
  - 图标：方形色块底 + 白色图标（Metro 磁贴感）
动效：150–200ms 颜色与位移过渡，ease-out，不做弹性效果
避免：渐变；投影；拟物纹理；同屏超过 4 种饱和色
英文关键词（可用于 AI 绘图 / 检索）：flat design, solid colors, no shadows, no gradients, metro tiles, simple geometric icons
```

## `skeuo` 拟物化（Skeuomorphism）
- 流行时期：2007 – 2013
- 特征：模仿真实材质：皮革、金属、木纹；高光、投影、缝线细节；控件像实物一样可“拧”可“按”
- 关键实现：`repeating-linear-gradient`、`inset box-shadow`
- 适用：音乐、相机、乐器、游戏道具
- 代表：iOS 6、早期 Mac、GarageBand
- 在线样本：https://itxd.github.io/wd-ui/#st-skeuo

```text
风格：拟物化（Skeuomorphism）
气质关键词：真实、可触摸、温暖、复古
配色：
  - 背景：皮革棕 #3B2516 → #6B4A32 径向渐变
  - 面板：拉丝金属 #C3C6CA–#E7E9EC
  - 强调：录音红 #C0161E → #FF6B6B
  - 文字：米白 #F5DEB3（带 0 1px 0 黑色文字阴影）
字体：衬线斜体做标签（Georgia italic），控件文字粗体并带压印阴影
形状与层次：圆角 10–14px；多层渐变 + 内高光 inset 0 1px 0 rgba(255,255,255,.5) + 外投影 0 6px 10px rgba(0,0,0,.4)
布局：模拟实体设备面板：缝线虚线边框、旋钮、仪表、实体按键
组件表现：
  - 按钮：上亮下暗渐变 + 底部 3px 深色“厚度”阴影，按下时下沉 2px
  - 旋钮：径向渐变金属球 + 红色指示刻度
  - 仪表：米黄表盘 + 摆动指针
  - 面板：repeating-linear-gradient 拉丝纹理
动效：指针缓慢摆动，按键按下位移 2px，模拟物理
避免：在数据密集界面使用；纹理过多导致文字难读
英文关键词（可用于 AI 绘图 / 检索）：skeuomorphic UI, leather texture, brushed metal, glossy buttons, realistic knobs, stitched borders
```

## `neu` 新拟态（Neumorphism）
- 流行时期：2019 –
- 特征：元素与背景同色；一亮一暗双阴影，像从表面“挤”出来；按下时变为内凹
- 关键实现：`box-shadow: 8px 8px 16px #a3b1c6, -8px -8px 16px #fff`、`inset`
- 适用：智能家居、计算器、音乐播放器（对比度低，慎用于重要信息）
- 代表：Dribbble 概念稿、部分 IoT 面板
- 在线样本：https://itxd.github.io/wd-ui/#st-neu

```text
风格：新拟态（Neumorphism）
气质关键词：柔和、安静、触感、未来感
配色：
  - 背景与表面（同色）：#E0E5EC（经典）；更干净的浅色版 #F1F4F8
  - 暗部阴影：#A3B1C6（浅色版用 #D3DAE5）
  - 亮部阴影：#FFFFFF
  - 文字：#3D4757 / 次要 #7B8798
  - 强调：#A78BFA → #EC4899 渐变（少量）
字体：无衬线，字重 500–600，颜色偏灰蓝
形状与层次：圆角 16–20px；凸起：8px 8px 16px #A3B1C6, -8px -8px 16px #FFFFFF；凹陷：inset 5px 5px 10px #A3B1C6, inset -5px -5px 10px #FFFFFF
布局：元素与背景同色，靠一明一暗双阴影“挤出”轮廓；留白充足
组件表现：
  - 按钮：凸起，按下或选中变凹陷，选中图标变强调色
  - 旋钮/仪表：外圈凸起、内圈凹陷
  - 输入框与滑轨：凹陷
  - 卡片：大圆角凸起
动效：200ms 阴影切换（凸 ↔ 凹），ease-out
避免：对比度不足导致不可读（正文至少 4.5:1）；用于重要操作的唯一提示
英文关键词（可用于 AI 绘图 / 检索）：neumorphism, soft UI, same-color background, dual soft shadows, extruded and pressed elements, #E0E5EC
```

- 适用：金融卡片、天气、音乐、系统浮层
- 代表：macOS Big Sur、Windows 11、visionOS
- 在线样本：https://itxd.github.io/wd-ui/#st-glass
