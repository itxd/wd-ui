# 页面模板

共 27 种常见页面。先选最接近的页面类型，再把布局和必备组件写进提示词。线框图：https://itxd.github.io/wd-ui/#pages

## 登录注册（Login / Sign up）· 通用

- 布局：左右分栏：左侧 55% 品牌插画或产品图（可放标语），右侧居中 360px 表单卡：Logo、标题“欢迎回来”、账号输入框、密码输入框（可切换明文）、记住我 + 忘记密码一行、全宽主按钮、分割线“或”、第三方登录图标按钮、底部“还没有账号？注册”
- 必备组件：表单、第三方登录、验证码、记住我

## 仪表盘（Dashboard）· 后台

- 布局：左侧导航 + 顶栏；内容区：页头（标题 + 时间筛选 + 导出）→ 4 张统计卡片一行（数值、涨跌、迷你图）→ 2:1 两张图表卡（趋势折线 + 占比环形）→ 2:1 表格卡 + 动态时间轴
- 必备组件：统计卡片、图表、表格、时间筛选

## 列表页（List / CRUD）· 后台

- 布局：左侧导航；内容区：页头（标题 + 新建主按钮）→ 查询表单卡（2–4 列条件 + 查询/重置）→ 表格卡（工具栏：批量操作 + 刷新/列设置/密度；选择提示条；带复选框、排序、状态标签、行操作的表格；底部分页）→ 编辑抽屉
- 必备组件：查询表单、表格、批量操作、分页

## 卡片网格（Card Grid）· 通用

- 布局：页头（标题 + 主按钮）→ 横向筛选纸片 → 3–4 列响应式卡片网格（封面图 4:3、标题、两行描述、底部元信息），滚动到底自动加载
- 必备组件：卡片、筛选标签、无限滚动

## 详情页（Detail）· 通用

- 布局：面包屑 → 左右布局（左主图/图集，右标题、关键信息、主次按钮）→ 线形标签页（详情 / 参数 / 记录）→ 描述列表（两列字段名-值）与正文
- 必备组件：面包屑、主图、描述列表、标签页

## 表单页（Form）· 通用

- 布局：居中 640px 卡片：分组标题 → 标签左对齐 120px 的表单项（输入框、下拉、单选组、日期、文本域）→ 必填红星与下方说明/错误文字 → 底部固定操作栏（取消 + 提交）
- 必备组件：表单项、校验、分组、提交栏

## 分步表单（Steps Wizard）· 通用

- 布局：顶部横向步骤条（4 步：已完成/当前/未开始）→ 当前步骤表单卡 → 底部上一步/下一步按钮；最后一步为确认信息 + 结果页
- 必备组件：步骤条、分步校验、上一步 / 下一步

## 设置页（Settings）· 通用

- 布局：左侧二级导航（个人资料 / 账号安全 / 通知 / 偏好 / 危险区）→ 右侧分组卡片，每行“标题 + 说明 + 右侧开关或按钮”，危险区红色描边
- 必备组件：分组导航、开关、单元格、危险区

## 个人主页（Profile）· App

- 布局：顶部封面图 → 左下压住封面的大头像 → 昵称、简介、关注按钮 → 关注 / 粉丝 / 获赞统计 → 内容标签页 → 3 列作品网格
- 必备组件：封面、头像、统计、内容标签页

## 搜索结果（Search Results）· Web

- 布局：顶部大搜索框（带清除与搜索建议）→ 结果类型纸片 + 排序 → 左侧结果列表（标题主色可点、URL、摘要中关键词高亮）→ 右侧筛选面板（复选框分组）→ 分页
- 必备组件：搜索框、筛选、高亮、排序

## 消息中心（Inbox）· 通用

- 布局：主从布局：左侧 40% 消息列表（头像、标题、摘要、时间、未读圆点，当前项浅主色底）→ 右侧详情（发送人、正文、附件、回复/归档按钮）；顶部“全部已读”
- 必备组件：主从布局、未读标记、批量已读

## 聊天 IM（Chat）· App

- 布局：三栏或两栏：会话列表（头像、昵称、最后一条、时间、未读数）→ 会话区（顶部对方信息、中间气泡流：左灰右主色、时间分隔、图片/文件卡）→ 底部输入栏（表情、附件、发送）
- 必备组件：会话列表、气泡、输入栏、表情

## 看板（Kanban）· Web

- 布局：页头（项目名 + 成员 + 视图切换）→ 筛选纸片 → 横向滚动的 4 列（待办 / 进行中 / 评审 / 完成），每列标题带数量与 +，卡片可拖拽（编号、标题、标签、负责人、截止日）
- 必备组件：列、可拖拽卡片、泳道、筛选

## 日历排期（Calendar）· 通用

- 布局：顶部月份切换 + 今天按钮 + 日/周/月分段控制器 → 7 列月视图网格，日期格内彩色事件条（左侧 2px 色条），今天日期主色圆形；点击日期新建事件
- 必备组件：月 / 周视图、事件块、拖拽改期

## 文件管理（File Manager）· Web

- 布局：左侧目录树 → 顶部面包屑路径 + 上传按钮 + 网格/列表切换 → 文件夹与文件网格（图标、名称、修改时间），支持拖拽上传与多选
- 必备组件：树形目录、网格 / 列表切换、上传

## 文章阅读（Article）· Web

- 布局：居中 680px 正文栏：标题（32px）→ 作者头像、名称、发布时间、阅读时长 → 封面大图 → 正文（17px / 1.8 行高，二级标题、引用块、代码块、图片说明）→ 右侧浮动目录 → 文末点赞分享与相关推荐
- 必备组件：标题、作者信息、正文排版、目录

## 落地页（Landing）· Web

- 布局：导航栏 → 首屏（徽章 + 大标题 + 副标题 + 两个 CTA + 产品截图）→ 客户 Logo 墙 → 功能区（便当格或三列）→ 数据亮点 → 用户评价 → 定价 → FAQ → 行动横幅 → 页脚
- 必备组件：导航、首屏、CTA、功能区、评价

## 定价页（Pricing）· Web

- 布局：标题 + 月付/年付切换（年付优惠标签）→ 3 档价格卡（中间推荐档高亮上浮 + 角标）→ 功能对比表（勾/叉）→ FAQ
- 必备组件：套餐卡片、周期切换、功能对比

## 商品列表（Product Listing）· 电商

- 布局：左侧筛选栏（分类、价格区间、品牌复选、评分）→ 顶部排序（综合 / 销量 / 价格 / 新品）与结果数 → 3–4 列商品卡（图片、标题两行、价格红色、销量、加购按钮）→ 分页或无限滚动
- 必备组件：筛选侧栏、排序、商品卡片、加购

## 购物车结算（Cart / Checkout）· 电商

- 布局：左侧商品行列表（复选框、缩略图、标题与规格、单价、数量步进器、小计、删除）→ 右侧吸顶订单汇总卡（商品金额、优惠、运费、应付合计大号红色、去结算主按钮）
- 必备组件：商品行、数量步进、优惠、订单汇总

## 结果页（Result）· 通用

- 布局：居中：64px 状态图标（成功绿色圆 + 勾，失败红色）→ 标题 → 说明（订单号、金额）→ 主按钮“查看详情”+ 次按钮“返回首页”→ 可选的后续步骤列表
- 必备组件：状态图标、说明、下一步操作

## 空状态 / 404（Empty / Error）· 通用

- 布局：居中：插画或大号渐变“404”→ 标题“页面走丢了”→ 原因说明 → 主按钮“返回首页”+ 搜索框或常用链接
- 必备组件：插画、原因说明、引导操作

## 地图 LBS（Map）· App

- 布局：全屏地图（道路、绿地、水域简化底图）→ 定位点（当前选中放大红色水滴）→ 顶部搜索框 → 底部可拖拽弹层（半屏，列表项：缩略图、名称、距离、评分）
- 必备组件：地图、定位点、底部弹层列表

## AI 对话（AI Chat）· Web

- 布局：左侧 260px 会话历史（新对话按钮 + 按日期分组的标题列表）→ 中间对话区（最大 760px，用户气泡靠右灰底，AI 回复左侧头像 + Markdown 内容 + 复制/重试/反馈）→ 底部固定提示词输入框（多行、附件、模型选择、发送）
- 必备组件：历史会话、流式回答、提示词输入框

## 引导页（Onboarding）· App

- 布局：全屏单页：顶部“跳过”→ 中间大插画 → 标题 + 两行说明 → 分页指示点（当前为胶囊）→ 底部全宽主按钮“下一步 / 开始使用”，左右滑动切换
- 必备组件：插画、分页点、跳过、开始使用

## 编辑器（Editor / Canvas）· Web

- 布局：顶部工具栏（撤销、形状、文本、图片、对齐、导出主按钮）→ 左侧图层面板 → 中间带点阵背景的画布（选中元素有主色描边与控制点）→ 右侧属性面板（尺寸、位置、填充、描边、圆角）
- 必备组件：工具栏、图层、画布、属性面板

## 数据大屏（Data Screen）· 后台

- 布局：深色背景 1920×1080：顶部发光标题栏 + 时钟 → 左右两列数据面板（细线框 + 角标：排行、柱状、环形、滚动告警）→ 中间数字翻牌器 + 飞线地图
- 必备组件：标题装饰、地图、翻牌器、轮播表
